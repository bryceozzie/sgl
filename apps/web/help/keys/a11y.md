# @a11y {#key/a11y}

What screen readers announce for a node, container or edge: a `label` in place of the visible text, and a longer `description`.

Aliases: accessibility, screen reader, aria, alt text

Each is plain text. Without them, a node is announced by its label or name, and an edge by its two ends and its label.

```sgl example title="A label and a description" contains="Takes card payments"
api: {
  @label: "API"
  @a11y: { label: "Payments API", description: "Takes card payments" }
}
```

See also: [Title](#help/key/title), [Tooltip](#help/key/tooltip)

## @a11y.label {#key/a11y.label}

The name a screen reader announces for the element, in place of its visible label.

Aliases: aria-label, accessible name

```sgl example title="An accessible name for an edge" contains="Orders flow to billing"
orders
billing
orders -> billing: { @a11y.label: "Orders flow to billing" }
```

See also: [Description](#help/key/a11y.description)

## @a11y.description {#key/a11y.description}

A longer description a screen reader offers after the name.

Aliases: aria-description, long description

```sgl example title="A description"
db: { @a11y.description: "Postgres, replicated across two regions" }
```

See also: [Label](#help/key/a11y.label)
